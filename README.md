
# Shader OSC APP

A Node Based OSC application built on Astro and Tauri, Fully Vibe Coded but otherwise basic functionality works just a hobby project and nothing much. Main Target Usage is for VR Chat

This is an Early Alpha and a basic proof of concept that a node based editor using webgl can incorporate shader pipelines to work.


## Features

- Multiple Themes
- Live previews
- Node Based Editing
- Built in Shader Pipeline for customisation


## Tech Stack

**Front:** ReactGraph, Astro, CSS

**Back:** Tauri
